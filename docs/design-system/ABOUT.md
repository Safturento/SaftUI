# About this folder

A copy of the source files of SaftUI's design system, which is published as a Design
System artifact on claude.ai (private to the repo's owner):
https://claude.ai/artifact/6uKajynejK1bdhqsDNnHJz

The artifact is the browsable version, with live previews; this folder is the copy that
travels with the code. `README.md` is the rules, `tokens.json` the values, `components/`
one folder per component (`README.md` guidelines, `preview.html` a static rendition),
`10-discrepancies.md`, `20-unknowns.md` and `30-code-changes.md` the audit's findings.
The fonts the previews use are the repo's own (`SaftUI-Core/Media/Fonts/`).

When the design system changes, change it in both places. First written 2026-11-13 from
an audit of the code at b14f81a, the approved mockups and in-game screenshots.
