# Spy skin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle Spy Forever's Nearby window, alert popup, Statistics window and KoS button in SaftUI's look, behind a Skinning page toggle.

**Architecture:** One new Skinning submodule, `SaftUI-Misc/Skinning/addons/spy.lua` (module `Spy`), in the pattern of `restedxp.lua` and `Blizzard_ColorPicker.lua`: post-hooks on Spy's functions and `HookScript` on its frames, SaftUI's panels drawn with `st:SetBackdropIn` into weak side tables keyed by Spy's frames, nothing written onto Spy's frames as fields. Tests run against a fixture of Spy's frames (`tests/misc/fixtures/spy_world.lua`) modelled on the owner's installed copy.

**Tech Stack:** Lua 5.1 (WoW addon API), SaftUI-Core helpers, the repo's `tests/run` harness.

**Spec:** `docs/superpowers/specs/2026-11-22-spy-skin-design.md`

## Global Constraints

- Spy reference source (the owner's Spy 1.3.8-forever28, read-only, never copied into the repo): `/tmp/claude-0/spyref/forever/` (`Widgets.lua`, `MainWindow.lua`, `Display.lua`, `SpyStats.xml`, `SpyStats.lua`, `Colors.lua`, `Spy.xml`). Fixtures model frame names, parentKeys and functions only.
- Read `.agents/taint.md` (the third-party note, line ~46, and rule 1's recipe) and `.agents/architecture.md` (theme kinds) before writing code.
- Never: `SetScript` on a Spy frame; a Lua field written onto a Spy frame or region; `SetSize`/`SetWidth`/`SetHeight`/`SetPoint`/`ClearAllPoints`/`Show`/`Hide`/`SetParent` on `Spy_MainWindow` or any `Spy_MainWindow_Bar<n>` row (secure; the window is protected in combat). Spy's non-secure pieces (title bar, buttons, grips, alert window, stats frame, KoS button) may be re-anchored, re-textured and faded.
- Every hook target is type-checked first; a missing one skips that piece silently (no error, the piece keeps Spy's look).
- Look: the Skinning page's `theme`, `background` and `font` (`st.config.profile.skinning`); titles in the font the color picker uses for its title (`TitleFont()` in `Blizzard_ColorPicker.lua`). Font sizes stay the ones Spy asks for (RestedXP's `HookFont` pattern); only face and outline change.
- New setting `skinning.spy = true` in `SaftUI-Misc/config.lua`, toggle `Spy` on the Skinning page (order after `color_picker`), desc: "Draw the Spy addon's Nearby window, alert, Statistics window and Kill on Sight button in SaftUI's look, in this page's Theme, Background and font. While on, Spy's Border and window colors are not used. Off, or while this page's Theme is Blizzard, Spy keeps its own look. Requires a reload."
- The skin installs only if, at setup, `skinning.spy` is on and the Theme is not `blizzard`. Theme/Background/font changes after that apply live through `UpdateConfig`, `OnColorsChanged`, `OnFontsChanged`.
- Hover on every SaftUI button and list line goes through `st:AddStates` / `st:SetState` (`tests/core/states_scan_test.lua` must stay green).
- Spy loads by `ADDON_LOADED` name `Spy`; `SpyStatsFrame` exists at Spy's load; `Spy.MainWindow`/`Spy.AlertWindow` after `Spy:CreateMainWindow`; `Spy.KoSButton` after `Spy:CreateKoSButton`.

## Review Focus

1. Combat: Spy calls `ResizeMainWindow`/`ManageBarsDisplayed`/`SetBar` in combat; the skin's hooks must not touch the window's or a row's geometry (test: with `stub.in_combat = true`, run those and assert no geometry call reached the window or rows).
2. Spy's own re-styling after the skin: `Spy:ApplyBorderStyle()` (profile change, Border option) and `Spy.Colors` refresh put backdrops and the gold `ForeverBorder` back; the skin must clear them again (test in Task 2).
3. Rows created later: Spy makes rows up to `ResizeSpyLimit` at window creation but `CreateRow` can run again when the limit grows; a late row must be skinned (test in Task 2).
4. The alert's border tint per alert kind: each `ShowAlert` recolors; SaftUI's panel border must follow the alert's color every time, not only the first (test in Task 3).
5. KoS button with no target / friendly target / SaftUI's unit frames off: hidden, hidden, left on Blizzard's frame (tests in Task 5).
